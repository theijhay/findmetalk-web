# Self-hosted Typeface: Noto Sans Variable

- **File:** `NotoSans-Variable.woff2`
- **Family:** Noto Sans (variable weight `100` to `900`, normal width `100%`)
- **Upstream project:** https://github.com/notofonts/latin-greek-cyrillic (`NotoSans` v2.015)
- **Distribution artifact:** Variable WOFF2 subset build (`latin` + `latin-ext` + combining diacritical marks) from `@fontsource-variable/noto-sans` (`v5.2.8`, https://cdn.jsdelivr.net/fontsource/fonts/noto-sans:vf@latest/latin-ext-wght-normal.woff2 mixed with full Latin/Latin-Ext variable table from Google Fonts `Noto Sans` v39 `o-0bIpQlx3QUlC5A4PNB6Ryti20_6n1iPHjc5a7duw.woff2`).
- **Character coverage:** Verified by `tests/design-system.test.ts` to include all required glyphs and combining marks for English, Nigerian Pidgin, Yoruba (`ẹ, ọ, ṣ` and combining tone marks `\u0301`, `\u0300`, `\u0304`, `\u0323`), Hausa (`ɓ, ɗ, ƙ, ƴ` uppercase and lowercase), Igbo (`ị, ọ, ụ, ṅ`), and French.
